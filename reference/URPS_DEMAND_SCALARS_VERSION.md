# Version of the URPS demand calibration scalar skeleton

Pre-calibration version `"0.1.0"` – all scalars are `1.0`. Bump to
`"1.0.0"` when NAMCS/NHAMCS/NIS totals are fitted.

## Usage

``` r
URPS_DEMAND_SCALARS_VERSION
```

## Format

Length-1 character string.
