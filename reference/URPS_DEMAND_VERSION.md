# Version of the URPS demand prediction equation skeleton

Pre-calibration version `"0.1.0"` – structure matches the HWMM
specification but all regression coefficients are `NA`. Bump to
`"1.0.0"` on first MEPS/NAMCS fit.

## Usage

``` r
URPS_DEMAND_VERSION
```

## Format

Length-1 character string.
