# Standard medical FTE reference (hours per week)

The denominator for the sex-stratified FTE weight: 40 hours per week =
1.0 FTE. A subspecialist working more than 40 hours per week at peak
career has an FTE weight \> 1. Used by
[`urps_fte_weight_sex()`](https://mufflyt.github.io/mufflyaccess/reference/urps_fte_weight_sex.md).

## Usage

``` r
URPS_FTE_REFERENCE_HOURS_PER_WEEK
```

## Format

Length-1 numeric.
