# Version of the URPS sex-stratified FTE hours model

Semantic version of the OLS coefficient set served by this package. Bump
when anchor points, coefficients, or the reference hours change.

## Usage

``` r
URPS_FTE_SEX_HOURS_VERSION
```

## Format

Length-1 character string (e.g. `"1.0.0"`).
