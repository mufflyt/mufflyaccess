# Version of the URPS labor force participation model

Semantic version of the logistic LFP parameter set. Bump when anchor
points or coefficients change.

## Usage

``` r
URPS_LFP_VERSION
```

## Format

Length-1 character string (e.g. `"1.0.0"`).
