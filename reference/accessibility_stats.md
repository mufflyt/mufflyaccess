# Accessibility-disparity pure statistics (SSOT)

Pure, dependency-light statistics shared by the isochrones and twostep
accessibility pipelines (population-weighted mean, zero-access share,
Monte-Carlo CI, OLS trend) plus the RUCA rurality map and ACS
year/vintage/ variable-code helpers. Promoted verbatim from
isochrones/R/accessibility_stratification.R (guarded there by
tests/testthat/test-accessibility-stratification.R) so isochrones +
twostep share ONE definition. Base R + `stats` only.
